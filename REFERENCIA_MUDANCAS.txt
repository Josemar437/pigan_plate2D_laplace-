## Mudanças em Utils.py

### Hard Constraint Mask - Função Reescrita (Linhas 130-183)

**Parâmetro novo**: `smooth_profile: str = "tanh"`

**Comportamento**:
- `smooth_profile = "tanh"`: Versão suavizada (padrão)
- `smooth_profile = "polynomial"`: Versão original

**Garantias**:
- φ(0, y) = 0 para todo y
- φ(Lx, y) = 0 para todo y
- φ(x, 0) = 0 para todo x
- φ(x, Ly) = 0 para todo x
- φ max = 1 (normalizado)
