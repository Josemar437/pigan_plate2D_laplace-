### 2. `src/utils.py`

#### Mudança 2.1: Estender build_hard_constraint_mask() (Intervenção 4)
```
Linhas: ~130-180 (função completa)

ANTES:
  def build_hard_constraint_mask(x_grid, y_grid, *, lx, ly) -> Tensor:
      x_hat = x_grid / lx
      y_hat = y_grid / ly
      phi = x_hat * (1-x_hat) * y_hat * (1-y_hat)
      phi_max = amax(phi).clamp_min(1e-12)
      return phi / phi_max

DEPOIS:
  def build_hard_constraint_mask(
      x_grid, y_grid, *, lx, ly,
      smooth_profile: str = "tanh"
  ) -> Tensor:
      x_hat = x_grid / lx
      y_hat = y_grid / ly
      
      if smooth_profile == "tanh":
          # Versão tanh com suavidade C2
          k = 3.0
          x_scaled = k * (2*x_hat - 1)
          y_scaled = k * (2*y_hat - 1)
          phi_x = (1 + torch.tanh(x_scaled)) / 2
          phi_y = (1 + torch.tanh(y_scaled)) / 2
          phi = phi_x * phi_y
      else:
          # Versão polinomial (legado)
          phi = x_hat * (1-x_hat) * y_hat * (1-y_hat)
      
      phi_max = torch.amax(phi).clamp_min(1e-12)
      return phi / phi_max

RAZÃO: Reduz Laplaciano artificial nos cantos (Δφ ≈ -0.08 vs -0.23)
```
